# Code of Conduct

## Our Standards

Participants in this project are expected to:

- be respectful and constructive in public discussions
- focus on technical content, not personal attacks
- accept feedback and resolve disagreements in good faith
- avoid harassment, discrimination, and intimidation

## Scope

This Code of Conduct applies to project spaces, including issues, pull requests, discussions, and release comments.

## Reporting

If you experience or witness unacceptable behavior:

- for non-security conduct issues, open a maintainer contact request through GitHub Issues after the repository is published
- for sensitive/security matters, follow [SECURITY.md](./SECURITY.md)

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates this policy and may limit participation for repeat or severe violations.
